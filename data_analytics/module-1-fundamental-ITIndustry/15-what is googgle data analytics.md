# What is Google Data Analytics?

**Google Data Analytics** is a professional certificate program offered by **Google** through **Coursera**. It is a beginner-friendly course designed to teach the skills needed to become a data analyst. The program covers the entire data analysis process — from asking the right questions to making data-driven decisions and communicating findings through visualizations.

## What You Will Learn

The Google Data Analytics Professional Certificate covers the **6 key phases of data analysis**:

### 1. Ask
- Define the business question or problem.
- Understand stakeholder expectations.
- Create effective data-driven questions.
- Identify metrics and goals for analysis.

### 2. Prepare
- Collect data from various sources (databases, spreadsheets, APIs).
- Understand data types and structures.
- Ensure data integrity and accuracy.
- Use spreadsheets (Google Sheets/Excel) for data organization.

### 3. Process
- Clean and organize raw data.
- Remove duplicates, handle missing values, and fix errors.
- Use SQL for data processing.
- Ensure data is ready for analysis.

### 4. Analyze
- Perform data analysis using SQL, R, and spreadsheets.
- Apply formulas, functions, and calculations.
- Identify patterns, trends, and relationships in data.
- Use basic statistics (mean, median, standard deviation).

### 5. Share
- Create visualizations using charts, graphs, and dashboards.
- Use **Tableau** and **Google Data Studio (Looker Studio)** for visualization.
- Build compelling data presentations.
- Communicate insights to stakeholders effectively.

### 6. Act
- Make data-driven decisions based on analysis.
- Implement recommendations.
- Measure the impact of decisions.
- Continuously monitor and improve.
