# What is Excel?

**Microsoft Excel** is a spreadsheet application developed by Microsoft. It is used to store, organize, analyze, calculate, and visualize data in tabular form (rows and columns). Excel is part of the Microsoft Office suite and is widely used in business, education, finance, and data analysis.

## Key Features of Excel

- **Formulas and Functions** - Perform calculations automatically (SUM, AVERAGE, COUNT, VLOOKUP, etc.).
- **Charts and Graphs** - Create visual representations of data (bar charts, pie charts, line graphs).
- **Pivot Tables** - Summarize and analyze large datasets.
- **Sorting and Filtering** - Organize data quickly.
- **Conditional Formatting** - Highlight cells based on conditions.
- **Data Validation** - Control what data can be entered in cells.
- **Macros (VBA)** - Automate repetitive tasks.
- **Multiple Sheets** - Organize data in different sheets within one file.

---

## What is a Workbook and Sheet?

- **Workbook** - An Excel file is called a workbook. It is the entire file that you save on your computer (e.g., `report.xlsx`).
- **Worksheet (Sheet)** - Each tab within a workbook is called a worksheet. A workbook can contain multiple sheets (Sheet1, Sheet2, Sheet3, etc.).

Think of a **workbook** as a notebook and **sheets** as individual pages within that notebook.

## How to Create a Workbook in Excel

### Method 1: From the Start Menu
1. Click on the **Start** button on your computer.
2. Search for **Microsoft Excel** in the search bar.
3. Click on the **Excel** application to open it.
4. On the welcome screen, click on **Blank Workbook**.
5. A new empty workbook will open with a default sheet (Sheet1).

### Method 2: Using Keyboard Shortcut
1. Open Microsoft Excel.
2. Press **Ctrl + N** on your keyboard.
3. A new blank workbook will be created instantly.

### Method 3: From File Menu (Inside Excel)
1. Open Microsoft Excel.
2. Click on the **File** tab in the top-left corner.
3. Click on **New**.
4. Select **Blank Workbook**.
5. A new workbook will open.

### Method 4: Right-Click Method (Desktop)
1. Right-click on an empty area of your desktop or in a folder.
2. Hover over **New**.
3. Click on **Microsoft Excel Worksheet**.
4. A new Excel file will be created on the desktop.
5. Double-click to open it.

## How to Create a Sheet (Worksheet) in Excel

### Method 1: Using the Plus (+) Button
1. Open an existing Excel workbook.
2. Look at the bottom of the screen where you see sheet tabs (Sheet1, Sheet2, etc.).
3. Click on the **plus (+)** icon next to the existing sheet tabs.
4. A new sheet (Sheet2, Sheet3, etc.) will be added.

### Method 2: Right-Click Method
1. Right-click on any existing sheet tab at the bottom of the screen.
2. Select **Insert** from the menu.
3. In the dialog box, select **Worksheet**.
4. Click **OK**.
5. A new sheet will be inserted.

### Method 3: Using Keyboard Shortcut
1. Press **Shift + F11** on your keyboard.
2. A new worksheet will be inserted before the currently active sheet.

### Method 4: Using the Ribbon Menu
1. Click on the **Home** tab in the ribbon.
2. Click on the **Cells** group.
3. Click on **Insert**.
4. Select **Insert Sheet**.

## How to Rename a Sheet

1. **Double-click** on the sheet tab name (e.g., Sheet1).
2. The tab name will become editable.
3. Type the new name (e.g., "Sales Data").
4. Press **Enter**.

Or

1. **Right-click** on the sheet tab.
2. Select **Rename**.
3. Type the new name and press **Enter**.

---

## How to Delete a Sheet

1. Right-click on the sheet tab you want to delete.
2. Select **Delete** from the menu.
3. Click **OK** to confirm (if the sheet has data, Excel will warn you).

---

## How to Move or Copy a Sheet

1. Right-click on the sheet tab.
2. Select **Move or Copy**.
3. Choose the destination workbook and position.
4. Check **Create a copy** if you want to duplicate the sheet.
5. Click **OK**.

## Common Excel File Formats

| Format | Extension | Description |
|--------|-----------|-------------|
| Excel Workbook | .xlsx | Default modern Excel format |
| Excel Macro-Enabled Workbook | .xlsm | Supports VBA macros |
| Excel 97-2003 Workbook | .xls | Older Excel format |
| CSV | .csv | Comma-separated values (plain text) |
| PDF | .pdf | Portable Document Format (read-only) |

## Short Answer

Excel is a spreadsheet application used for data storage, calculation, and analysis. A **workbook** is the Excel file itself, and **sheets** are individual tabs within that file. To create a workbook, open Excel and select Blank Workbook. To create a sheet, click the (+) button at the bottom of the screen or press Shift + F11.
