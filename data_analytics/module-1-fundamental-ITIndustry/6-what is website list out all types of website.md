# What is a Website?

A **website** is a collection of web pages and related content that is identified by a common domain name and published on at least one web server. Websites are accessed through the internet using web browsers. Each website has a unique URL (web address) that users type to access it.

## How Does a Website Work?

1. A user types a URL in a web browser.
2. The browser sends a request to the web server hosting the website.
3. The server processes the request and sends back the web page files.
4. The browser renders the files and displays the website on the screen.

## Types of Websites

### 1. Static Website
- Contains fixed content that does not change unless manually updated.
- Built using HTML, CSS, and JavaScript.
- Content is the same for every visitor.
- Fast to load and easy to host.
- Example: A small business information page or personal portfolio.

### 2. Dynamic Website
- Content changes based on user interaction, time, or other factors.
- Uses server-side scripting languages like PHP, Python, or Node.js.
- Content is pulled from databases and generated in real-time.
- Example: Social media platforms, news websites, e-commerce sites.

### 3. E-commerce Website
- Designed for buying and selling products or services online.
- Includes features like shopping carts, payment gateways, and product catalogs.
- Example: Amazon, Flipkart, eBay, Myntra.

### 4. Blog Website
- A regularly updated website where individuals or groups share articles and posts.
- Content is displayed in reverse chronological order.
- Example: WordPress blogs, Medium, personal blogs.

### 5. Portfolio Website
- Showcase of an individual's or company's work, skills, and projects.
- Used by designers, developers, photographers, and freelancers.
- Example: Personal portfolio of a web developer or graphic designer.

### 6. Social Media Website
- Allows users to create profiles, share content, and interact with others.
- Includes features like posts, comments, likes, and messaging.
- Example: Facebook, Instagram, Twitter (X), LinkedIn, YouTube.

### 7. Educational Website
- Provides learning resources, courses, and educational content.
- Example: Khan Academy, Coursera, Byju's, Wikipedia, Unacademy.

### 8. News Website
- Publishes current events, news articles, and journalism.
- Updated frequently throughout the day.
- Example: BBC, CNN, Times of India, NDTV.

### 9. Business/Corporate Website
- Represents a company or organization online.
- Provides information about products, services, team, and contact details.
- Example: Company websites like TCS, Infosys, Reliance.

### 10. Forum Website
- An online discussion board where users can post questions and answers.
- Users interact through threads and replies.
- Example: Quora, Reddit, Stack Overflow.

### 11. Wiki Website
- A collaborative website where users can create and edit content.
- Content is built by community contributions.
- Example: Wikipedia, WikiHow.

### 12. Entertainment Website
- Provides entertainment content like movies, music, games, and videos.
- Example: Netflix, Spotify, IMDB, gaming websites.

### 13. Search Engine Website
- A website that helps users find information on the internet.
- Example: Google, Bing, Yahoo.

### 14. Directory Website
- A categorized list of websites and businesses.
- Example: Yellow Pages, Yelp, JustDial.

### 15. Non-Profit Website
- Created by non-profit organizations to share their mission and activities.
- Example: WWF, Red Cross, NGOs websites.

### 16. Web Application (Web App)
- A software application that runs in a web browser.
- Provides interactive functionality similar to desktop applications.
- Example: Gmail, Google Docs, Trello, Slack.

## Difference Between Static and Dynamic Websites

| Feature | Static Website | Dynamic Website |
|---------|---------------|-----------------|
| Content | Fixed, same for all users | Changes based on user interaction |
| Technologies | HTML, CSS, JavaScript | PHP, Python, Node.js, Databases |
| Speed | Faster | Slower (processes requests) |
| Hosting Cost | Lower | Higher |
| Database | Not required | Required |
| Examples | Portfolio site | Social media, E-commerce |

## Short Answer

A website is a collection of web pages accessible through the internet. The main types of websites are Static, Dynamic, E-commerce, Blog, Portfolio, Social Media, Educational, News, Business, Forum, Wiki, and Web Applications.
