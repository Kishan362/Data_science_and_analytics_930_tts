# What is Data?

**Data** is a collection of raw facts, figures, symbols, observations, and information that can be processed, analyzed, and interpreted to derive meaningful insights. Data can be in the form of text, numbers, images, audio, video, or any other format. When raw data is organized, structured, and analyzed, it becomes **information** that helps in decision-making.

## Simple Example

- Raw Data: 85, 90, 78, 92, 88
- Processed Information: The average score of 5 students is 86.6

---

## Types of Data

Data can be classified in different ways based on structure, source, and nature.

---

## 1. Based on Structure

### a. Structured Data
- Data that is organized in a predefined format, usually in rows and columns (tables).
- Easy to store, search, and analyze.
- Stored in relational databases (SQL).
- Example: Excel spreadsheets, database tables, CSV files.

**Example:**

| Name | Age | City |
|------|-----|------|
| Rahul | 25 | Delhi |
| Priya | 30 | Mumbai |

### b. Semi-Structured Data
- Data that does not follow a strict table format but has some organizational properties like tags or markers.
- Not stored in traditional databases but uses tags or keys for organization.
- Example: JSON files, XML files, email (sender, subject, body), HTML pages.

**Example (JSON):**
```json
{
  "name": "Rahul",
  "age": 25,
  "city": "Delhi"
}
```

### c. Unstructured Data
- Data that has no predefined format or organization.
- Most common type of data (about 80-90% of all data).
- Difficult to store and analyze using traditional methods.
- Example: Images, videos, audio files, PDF documents, social media posts, text messages.

---

## 2. Based on Nature

### a. Quantitative Data
- Data that can be measured and expressed in numbers.
- Can be mathematically calculated and analyzed.

#### Types of Quantitative Data:

**i. Discrete Data**
- Countable, whole numbers only.
- Cannot have decimal values.
- Example: Number of students in a class (30, 31, 32), number of cars in a parking lot.

**ii. Continuous Data**
- Measurable values that can have decimals.
- Can take any value within a range.
- Example: Temperature (36.5°C), height (5.8 feet), weight (70.5 kg), time.

### b. Qualitative Data (Categorical Data)
- Data that describes qualities or characteristics.
- Cannot be measured numerically.
- Expressed in words, labels, or categories.

#### Types of Qualitative Data:

**i. Nominal Data**
- Categories with no natural order or ranking.
- Example: Gender (Male, Female), Color (Red, Blue, Green), Blood Group (A, B, O).

**ii. Ordinal Data**
- Categories with a meaningful order or ranking.
- The difference between values is not measurable.
- Example: Rating (1-star to 5-star), Education Level (High School, Bachelor's, Master's), Customer Satisfaction (Poor, Good, Excellent).

---

## 3. Based on Source

### a. Primary Data
- Data collected firsthand for a specific purpose.
- Original and direct from the source.
- Example: Survey responses, interview data, experiment results, observations.

### b. Secondary Data
- Data that has already been collected and published by someone else.
- Indirectly obtained from existing sources.
- Example: Government census data, research papers, newspaper articles, Wikipedia.

---

## 4. Based on Time

### a. Real-Time Data
- Data that is collected and processed instantly as events occur.
- Example: Live stock market prices, live GPS tracking, weather updates.

### b. Historical Data
- Data that has been collected and stored from past events.
- Used for analysis, trends, and forecasting.
- Example: Last year's sales data, historical weather data.

---

## 5. Based on Collection Method

### a. Text Data
- Data in the form of words, sentences, and paragraphs.
- Example: Emails, chat messages, documents, reviews.

### b. Numerical Data
- Data expressed as numbers only.
- Example: Salary figures, test scores, age, temperature.

### c. Audio Data
- Data in the form of sound recordings.
- Example: Music files, voice recordings, podcast episodes.

### d. Video Data
- Data in the form of moving visual content.
- Example: YouTube videos, surveillance footage, video calls.

### e. Image Data
- Data in the form of pictures or visual content.
- Example: Photographs, X-rays, satellite images, screenshots.

---

## 6. Based on Handling in Data Analytics

### a. Raw Data
- Data in its original, unprocessed form.
- Has not been cleaned or organized.
- Example: Survey answers before formatting.

### b. Clean Data
- Data that has been processed, cleaned, and organized for analysis.
- Free from errors, duplicates, and inconsistencies.

### c. Big Data
- Extremely large volumes of data that cannot be processed by traditional methods.
- Characterized by Volume, Velocity, and Variety (3Vs).
- Example: Social media data, IoT sensor data, search engine data.

---

## Short Answer

Data is raw facts and figures that can be processed to get meaningful information. The main types of data include Structured, Semi-Structured, and Unstructured data; Quantitative (Discrete, Continuous) and Qualitative (Nominal, Ordinal) data; Primary and Secondary data; and Real-Time and Historical data.
